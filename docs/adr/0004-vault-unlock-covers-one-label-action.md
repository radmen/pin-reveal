# Vault Unlock Covers One Label Action

A Vault Unlock should cover either one selected-label reveal or one post-reveal save, not an open-ended Vault session. If the user unlocks the Vault to select a Saved Label, the Vault Key may remain in memory through that one label's reveal so the app can automatically update the Saved Label afterward; if the user unlocks after manually revealing a label, the app saves or updates that one label and locks immediately. Any unlocked Vault access expires after 60 seconds if the reveal or save action does not complete, limiting exposure without requiring a second biometric prompt for the common select-and-reveal path. If that timeout expires after a Saved Label fills the form, the form remains usable, but the post-reveal update requires a fresh Vault Unlock.
